# 暗影奇譚・魔幻暗棋 (Dark Fantasy Banqi 3D)

一款結合 **Three.js 3D 寫實光影渲染**、**奇幻暗黑史詩擬人角色**、**專屬中文配音與擬真木棋音效** 以及 **電影感片頭影片** 的台灣暗棋（半盤象棋）網頁遊戲。

👉 **線上直接遊玩（GitHub Pages）**：https://allen640107-gh.github.io/dark-fantasy-banqi/

## 遊戲特色
- **雙陣營 14 位擬人化奇幻英雄**：**烈焰聖殿（紅方）** vs **冥淵暗影（黑方）**，搭配立體字章確保清晰辨識度。
- **3D 寫實暗黑棋盤**：深色紅木銅鉚釘框架、黑曜石刻紋棋盤、動態火光／冥光與飄浮粒子，支援三段視角切換與右鍵自由微調。
- **完整台灣暗棋規則與三段難度 AI**：支援單人對戰 AI（簡單／普通／困難）與雙人同機對戰，內建炮隔山打牛、兵卒斬帥、50 步防呆和局、陣亡算牌區、悔棋，以及可選的「暗棋連吃（連殺）」規則。
- **沉浸式影音體驗**：內建 9.5 秒片頭動畫、22 句台灣中文角色／系統配音、多層次擬真木棋與戰鬥音效，以及暗黑戰鼓循環 BGM。

## 本機啟動方式
在專案根目錄雙擊 `start_game.bat`，或執行：
```bash
python -m http.server 8765
```
接著以瀏覽器開啟 `http://localhost:8765`。
